# إصلاحات مراجعة ActivityMonitor — 15 أكتوبر 2026

تم تعديل المصدر والإعدادات والاختبارات وسكربتات الحزمة. لم تُشغّل عملية التقاط شاشة أو صوت حقيقية، ولم يُنفّذ تثبيت أو إلغاء تثبيت أو تغيير لخدمات الجهاز أو سجل بدء تشغيله. ملف الاختبار المرئي اصطناعي، مولد من canvas بلون ثابت ومربع متحرك، دون قراءة الشاشة أو الميكروفون.

## التغييرات المهمة للاستخدام والترقية

- بيانات Agent وViewer الجديدة داخل `%LOCALAPPDATA%\ActivityMonitor` لكل حساب Windows، بصلاحيات مالك الحساب وSYSTEM والمسؤولين. يظل المالك قادرًا على تعديل بياناته؛ لم يُنشأ سجل جنائي محصّن ضد مالكه.
- الأرشيف السابق داخل `%ProgramData%\ActivityMonitor` محفوظ، ويقيّد المثبت الجديد الوصول إليه للمسؤول وSYSTEM، مع إبقاء ملف افتراضات الإعداد قابلًا للقراءة. هذه الصلاحيات لا تتغير في تثبيت قائم قبل تشغيل المثبت المحدث.
- لعرض الأرشيف السابق، شغّل Viewer كمسؤول مع `--legacy-archive`. لمراجعة حساب آخر، استخدم كمسؤول `--user-store "C:\Users\OtherUser\AppData\Local\ActivityMonitor"`. لا يمنح وضع المراجعة التحكم في Agent أو الإعدادات.
- الصيانة الخاصة بالمستخدم تعمل داخل Agent، والخدمة تصون الأرشيف المشترك السابق. الحساب الذي لا يشغّل Agent تُطبّق صيانته عند التشغيل التالي.
- المثبت لا يشغّل التسجيل فورًا افتراضيًا؛ يبدأ Agent عند دخول المستخدم التالي أو من العارض. توجد وصلة واضحة في قائمة ابدأ، ولم تعد واجهة الصوت توصي بإخفاء مؤشرات التسجيل.
- مخطط SQLite أصبح الإصدار 2، بترقية إضافية للأعمدة وفهارس الجلسة والنبضة، ونسخة احتياطية قبل ترقية مخطط سابق. لا تُنقل بيانات الأرشيف المختلط تلقائيًا إلى حساب مستخدم.
